# A Paired Dataset of Human and VLM-Generated Painting Descriptions in Russian

This repository contains a paired Russian-language corpus of human-authored and vision-language-model-generated descriptions of paintings from the State Hermitage Museum collection.

The dataset was created to study how humans and multimodal language models perceive, select, organise, and verbalise information from the same visual stimuli.

## Dataset overview

The dataset contains descriptions of **895 paintings** from the State Hermitage Museum.

In total, it includes **6,606 Russian-language descriptions**:

- **3,921 human-generated descriptions**
- **895 Yandex VLM descriptions**
- **895 Gemma 3 27B descriptions**
- **895 Qwen3-VL 30B descriptions**

Human participants and the three vision-language models described the same paintings under comparable instructions, which makes the dataset suitable for controlled human–AI comparison.

The corpus is accompanied by structured artwork metadata, including information such as author, place and date of creation, museum department, collection, inventory number, category, and museum location.

## Human descriptions

Human descriptions were produced by non-expert volunteer informants.

Participants were asked to focus on what was depicted in the painting and to describe it as if they wanted to find the painting online without knowing its author or title.

Each artwork has between **1 and 12 human descriptions**.

The original texts were preserved without spelling, grammatical, stylistic, or syntactic normalisation.

## VLM-generated descriptions

Each of the 895 paintings was processed by three vision-language models:

- **Yandex VLM**
- **Gemma 3 27B**
- **Qwen3-VL 30B**

All models received the visual stimulus and a Russian-language prompt designed to elicit a natural description of the depicted content.

The generated outputs were preserved without manual editing, shortening, stylistic normalisation, or linguistic correction.

## Dataset structure

The main dataset is provided as:

`hermitage_data_v2.csv`

It contains **895 rows**, with one row corresponding to one artwork.

Main fields include:

| Column | Description |
|---|---|
| `id` | Unique artwork identifier |
| `title` | Artwork title |
| `author` | Author or creator |
| `place_of_creation` | Place of origin or creation |
| `date_of_creation` | Date or period of creation |
| `department` | Museum department |
| `collection` | Collection |
| `inventory_number` | Museum inventory number |
| `acquisition` | Acquisition information |
| `category` | Artwork category |
| `description` | Curatorial description |
| `building` | Museum building |
| `halls` | Hall or room number(s) |
| `url` | Permanent link to the artwork in the Hermitage online catalogue |
| `human_description_1`–`human_description_12` | Human-authored descriptions |
| `yandex_vlm` | Description generated by Yandex VLM |
| `gemma` | Description generated by Gemma 3 27B |
| `qwen` | Description generated by Qwen3-VL 30B |

Missing human-description fields indicate that fewer than twelve responses were collected for the corresponding artwork. These values were not artificially imputed or balanced.

## Perceptual and interpretative annotation

The project also investigates the distinction between **perceptual** and **interpretative** vocabulary.

Perceptual vocabulary refers to linguistic units grounded primarily in directly observable features of the image, such as objects, colours, spatial relations, physical properties, and visible actions.

Interpretative vocabulary includes information that requires inference, evaluation, cultural knowledge, social categorisation, religious or historical interpretation, or other forms of knowledge extending beyond directly visible properties.

A fine-grained annotation pipeline was developed to analyse these strategies in human and model-generated descriptions.

This makes it possible to investigate not only **what** humans and models describe, but also **how they linguistically conceptualise the same visual material**.

## Potential uses

The dataset can support research in:

- human–AI comparative stylistics
- corpus linguistics
- cognitive linguistics
- multimodal language modelling
- visual perception and verbalisation
- perceptual vs. interpretative language
- machine-generated text detection in Russian
- lexical and morphosyntactic analysis
- artwork and museum description generation
- accessibility-oriented museum text generation
- computational aesthetics
- cross-modal semantics

Because human and machine descriptions refer to the same visual stimuli, the dataset provides a controlled setting for comparing linguistic behaviour while keeping the underlying content relatively constant.

## Important usage notes

When comparing human and model-generated texts, differences in text length should be taken into account. The models, particularly Qwen3-VL, tend to generate substantially longer descriptions than human informants.

Raw lexical or syntactic frequencies should therefore be normalised before comparison.

For machine-generated-text detection experiments, train/test splits should be performed **by artwork rather than by individual description**, since multiple texts may correspond to the same image.

When analysing description strategies, it is also recommended to stratify the corpus by artwork metadata such as period, genre, collection, or place of creation.

## Images and copyright

The original artwork image files are **not redistributed in this repository**.

The dataset instead contains artwork identifiers, metadata, and links to the corresponding records in the State Hermitage Museum online collection.

Researchers should consult the museum's terms and policies when using artwork images in publications or derivative resources.
